# CubarmySpire — User Documentation

---

## 1. Overview

**CubarmySpire** is a roguelike auto-battler where the player commands a growing army through progressively harder dungeon stages. The game combines strategic preparation (army composition, equipment, upgrades) with real-time automated combat and light tactical control.

The goal is to progress as far as possible in a single run while strengthening your army between runs.

---

## 2. Core Gameplay Concept

The game is structured around **runs**:

1. Prepare your army (units, equipment)
2. Start a run from the Campaign
3. Progress through stages (floors)
4. Choose powerups after each victory
5. Lose → collect rewards → return to preparation

Each run is temporary, but progression is persistent.

---

## 3. Main Features

### 3.1 Army Management
- Build your army from available units
- Move units between:
  - **Active Army** (used in battles)
  - **Barracks** (stored units)
- Units have:
  - Type (e.g. Warrior, Ranger)
  - Level (affects stats)

---

### 3.2 Equipment System
- Equip items to improve your army
- Equipment types:
  - Weapon
  - Armor
  - Artifacts (multiple slots)
- Equipment can:
  - Boost stats
  - Modify gameplay behavior
  - Provide special effects

---

### 3.3 Powerups (Run-Based)
- After each stage, choose one powerup
- Powerups:
  - Stack over time
  - Only last for the current run
- Effects include:
  - Stat increases
  - Army size changes
  - Special mechanics

---

### 3.4 Auto-Battle System
- Units fight automatically in real time
- Player influence is limited to:
  - Selecting units
  - Issuing movement commands
- Combat outcome depends on:
  - Unit composition
  - Equipment
  - Powerups
  - Positioning

---

### 3.5 RTS Controls (During Battle)
- **Left Click:** Select unit
- **Drag:** Select multiple units
- **Double Click:** Select all units of same type
- **Right Click:** Move selected units in formation

---

### 3.6 Progression
- Earn rewards after each run:
  - Gold
  - Materials
- Use resources to:
  - Recruit units
  - Buy equipment
  - Craft items

---

### 3.7 Difficulty System
- Choose difficulty before starting a run:
  - Easy
  - Normal
  - Hard
- Higher difficulty:
  - Stronger enemies
  - Faster scaling

---

## 4. Game Flow

### 4.1 Starting the Game
- Launch game → Start Game
- A save is automatically created or loaded

---

### 4.2 Campaign Screen
- Select difficulty
- View your army and equipment
- Start a new run

---

### 4.3 Battle Loop
Each stage follows:

1. Army spawns
2. Combat happens automatically
3. If you win:
   - Collect loot
   - Choose powerup
   - Proceed to next stage
4. If you lose:
   - Run ends
   - Rewards are saved

---

### 4.4 After Run
You return to preparation screens:
- Improve army
- Manage inventory
- Start another run

## 8. Run Mechanics

### 8.1 Winning
- Continue to next stage
- Gain powerup

### 8.2 Losing
- Run ends
- Rewards are saved

### 8.3 Abandoning
- Return to Campaign
- **No rewards are saved**

---

## 9. Tips for Players

- Balance melee and ranged units
- Use equipment to define your strategy
- Powerups stack — plan synergy
- Positioning matters even in auto-battles
- Higher difficulty increases rewards but risk

---

## 10. Limitations

- Only one save slot is currently available
- Some UI/stat tracking features are minimal
- Game focuses on core loop rather than narrative

---

## 11. Summary

CubarmySpire is a loop-driven strategy game where success depends on:
- Smart preparation
- Synergistic upgrades
- Efficient army scaling

Each run is an opportunity to push further and refine your strategy.
